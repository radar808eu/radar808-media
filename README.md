# RADAR 808 media

Public media host for @radar808.eu (Instagram & TikTok). Slides are uploaded here by the nightly automation and scheduled through Metricool.

- `engine/` — graphic engine (approved by Riccardo): `radar808_engine.py` (carousel slides, IG 4:5 + TikTok 9:16), `radar808_stories.py` (Instagram stories), `to_jpg.py`.
- `posts/YYYY-MM-DD/<slug>/` — JPEG slides of each scheduled post (`IG_NN.jpg`, `TT_NN.jpg`, `story_*.jpg`).
